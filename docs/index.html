Download

Um único clone, três scripts de inicialização. O Nexus Forge baixa a engine Godot 4.3 oficial automaticamente no primeiro uso — nenhum setup manual de engine necessário.

Linux PRONTO

Distribuições x64 (Ubuntu/Mint/Fedora/Arch) e ARM64. Validado de ponta a ponta: geração, validação headless e execução do editor.

Launcher: scripts/start.sh
Windows COMPATÍVEL

Windows 10/11 x64. O core roda em Bun (nativo em Windows) e o adapter Godot baixa o binário oficial win64.exe automaticamente.

Launcher: scripts/start.bat
macOS COMPATÍVEL

Apple Silicon e Intel. Baixa o binário universal oficial do Godot 4.3 e detecta instalações em /Applications automaticamente.

Launcher: scripts/start.command
1

Clone o repositório (somente leitura — alterações apenas via pull request):

git clone https://github.com/yuaberry/nexus-forge.git cd nexus-forge
2

Instale o Bun (runtime do core — único requisito global):

# Linux / macOS curl -fsSL https://bun.sh/install | bash # Windows (PowerShell): # irm bun.sh/install.ps1 | iex
3

Inicie o estúdio — o script instala dependências, compila a UI, baixa o Godot 4.3 se necessário e sobe o servidor:

# Linux ./scripts/start.sh # Windows scripts\start.bat # macOS ./scripts/start.command
4

Abra o estúdio em http://127.0.0.1:5180 — depois (opcional) importe sua chave OpenRouter em Settings para ativar os agentes LLM. Sem chave, o Nexus roda em modo determinístico com templates reais.

Sobre o projeto

O Nexus Forge não é um chatbot que cospe código. É um estúdio de desenvolvimento autônomo: você atua como diretor criativo — descreve o jogo — e uma equipe de agentes de IA executa o trabalho técnico, com todo o processo auditável, versionado e validado por engine de verdade.

Game DNA persistente

Cada decisão de design fica registrada com origem: confirmada, inferida ou duvidosa. Agentes nunca contradizem o DNA aprovado.

Agentes com validação real

O Coder gera GDScript, o QA valida de verdade no Godot headless, o Fixer corrige erros exatos — até 3 rodadas, sem fingir sucesso.

Git nativo por task

Cada tarefa termina em commit auditável com diff. Snapshots antes de grandes alterações e histórico completo por projeto.

Provider-agnóstico

Interface AIProvider com OpenRouter funcional hoje; abstrações prontas para OpenAI-compatível, Ollama e modelos locais.

Multi-engine por adapters

Godot 4 integrado de ponta a ponta (download oficial, scaffold, validação headless). Unreal 5 com scaffold C++ real; Unity na arquitetura.

Segurança primeiro

Chaves em AES-256-GCM fora do repositório, workspace com sandbox de path, zero segredos no código.
