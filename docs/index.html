O MOTOR DE PRODUÇÃO

Um estúdio inteiro em um aplicativo

Cada capacidade é real e validada — nada de botões decorativos.

Game DNA persistente

Toda decisão de design fica registrada com origem (confirmada / inferida / duvidosa). Os agentes nunca contradizem o DNA aprovado.

Live Preview embutido

O botão ▶ exporta o jogo para Web com o Godot real e o roda DENTRO do estúdio — como o Play de uma engine.

Git nativo por task

Cada tarefa termina em commit auditável com diff. Snapshots antes de grandes alterações e histórico completo.

Agentes + validação real

O Coder gera GDScript, o QA valida no Godot headless, o Fixer corrige erros exatos — sem fingir sucesso, nunca.

Multi-engine por adapters

Godot 4 integrado de ponta a ponta. Unreal 5 com scaffold C++ real. Unity já prevista na arquitetura.

Steam Publish Kit

Descrição de loja, capsules nas resoluções oficiais Steam, screenshots reais do jogo e textos legais — gerados por projeto.
